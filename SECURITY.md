# Security

Please report security issues privately using [GitHub private vulnerability reporting](https://github.com/sour4bh/mac-dualsense/security/advisories/new). Do not include exploit details, credentials, or sensitive logs in a public issue.

Include the affected commit or release, macOS version, steps to reproduce, and the expected versus actual behavior. The maintainer reviews reports on a best-effort basis; there is no guaranteed response time.

The initial public binary release is being prepared. Security fixes target the latest released version and the current main branch.

This app intentionally injects keyboard and mouse input using Accessibility permission. A vulnerability report should describe an unintended action or boundary violation, rather than normal execution of a user-configured mapping. See [privacy and permissions](docs/privacy.md).
